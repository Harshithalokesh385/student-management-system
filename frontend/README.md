# Student Management System - Frontend

This is the frontend of the Student Management System, developed using React and Vite.

## Technologies Used

- React
- Vite
- JavaScript
- HTML
- CSS

## Features

- Add student
- View student list
- Edit student details
- Delete student
- Form validation
- Delete confirmation
- Responsive design
- Connects with Spring Boot REST APIs

## Backend API

The frontend communicates with the Spring Boot backend using REST APIs.
